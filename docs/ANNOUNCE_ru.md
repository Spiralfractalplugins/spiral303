# Spiral303 — Анонс (RU)

## Кратко (stories / X / подпись к рилу)

**🌀 Spiral303 — кислотная 303-линия, которая умеет говорить.**

Семь моделей фильтра, включая банк формант: ручка Cutoff ведёт голос по
траектории `у → о → а → э → и`, и нота буквально произносит гласную.
Секвенсор-спираль с gate-колесом, импорт `.mid` из DAW, четыре скина интерфейса.
VST3 + AU + Standalone, macOS universal / Windows / Linux.

Автор: **Spiralfractal**

## Подробно (пост)

**🌀 Spiral303 — кислотный ситнезатор**

Не ещё один «кислотный» плагин с одной косметической ручкой Filter. Здесь звук
строит живой тракт: морфинг-осциллятор синус → пила → квадрат с Polynomial Band-Limited Step (polyBLEP),
контурный резонансный фильтр 12/24 dB/oct с огибающей по срезу, акцент, глайд и
аналоговый дрейф — а поверх этого семь моделей фильтра, у каждой своя характерная
громкость, так что переключение не оглушает и не глохнет.

🎛 **Что внутри**
- **7 моделей фильтра**: классический контур Roland TB303, диодный, лестничный,
  TPT SVF, Sallen-Key, однополюсник и **Vowel**
- **Vowel — фильтр, который говорит.** Три параллельных формантных резонатора
  (F1/F2/F3), ручка Cutoff = положение во рту, Resonance = ширина формант, а
  огибающая ноты сама двигает «рот»: атака яркая, хвост тёмный. Нота произносит
  `у → о → а → э → и`
- **Секвенсор в стиле 303**: 8/12/16/24/32 шага, 12 гамм, на каждой ступени
  tie / slide / accent; свинг, glide, акцент-огибающая
- **Gate-колесо** — 16 секторов вокруг круга: закрытые гасят ноту, поворот
  сдвигает рисунок по доле. Отсюда stutter, roll и chop-рисунки
- **Импорт MIDI-фраз**: кнопка `MIDI` или бросок `.mid` в окно. Берётся самая
  низкая дорожка (бас, а не бочка), сетка 1/16, темп — из часов хоста, а строй и
  лад остаются ваши: чужие ноты прижимаются к ближайшей ступени
- **Аналоговость на ручке Warmth**: дрейф высоты тона и среза, флуктуации,
  разброс порога гейта
- Живой **осциллограф + АЧХ**, и АЧХ — орган управления: тянешь мышью
  (X = срез, Y = резонанс), колесо = срез; ручки едут за графиком
- Мастер-лимитер, метр, сатурация (tanh / drive / triode / fold / пять tape-моделей)
- **Пресеты** — известные acid-линии и 10 psytrance-паттернов,
  плюс свои пресеты в простом JSON и drag&drop файла в окно
- **4 скина интерфейса**: тёмный плоский, пульт космического корабля, орех с
  бакелитовыми ручками, шлифованный металл. Переключается на лету, звук при этом
  побитово идентичен
- Экспорт паттерна в WAV прямо из плагина
- VST3 + AU + Standalone, macOS universal / Windows / Linux

📐 **Проверено, а не обещано.** Весь DSP и секвенсор прогоняются офлайн в тестах
(896 проверок), интерфейс проверяется пиксельно, импортированная MIDI-линия
звучит **побитово идентично** той же линии, набранной руками, а движок укладывается
в ~0,2% реального времени по CPU.

Попробуйте: **FilterType = Vowel**, Resonance вправо,
проведите Cutoff от низов вверх — и послушайте, как бас говорит гласные.

Автор: **Spiralfractal**

(`Spiral303Tests`, скин Console). Пересобрать после релиза:

```sh
cmake --build build --config Release --target Spiral303Tests
./build/Spiral303Tests_artefacts/Release/Spiral303Tests
cp "$TMPDIR/Spiral303Tests/spiral303_gui/skin-1-console.png" docs/screenshots/ui-console.png
uv run --python 3.12 --with pillow docs/marketing/make_cards.py
```

Тексты карточек и версия — в `COPY` / `VERSION` внутри `make_cards.py`.
